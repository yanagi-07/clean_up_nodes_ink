# Ink_clean_out_nodes

Inkscape 用の拡張機能 `重複ノードを整理` (`clean_out_nodes`) です。  
連続して重なっている重複ノードを 1 つにまとめ、シャープノードとして整理します。

## できること

- 事前に選択した `path` 要素だけを対象に重複ノードを整理
- `チェックのみ` で重複候補の有無だけを確認
- 重複候補ノードへ赤い補助マーカーを作成
- 選択パス内のノード総数とノード種類ごとの数を表示
- 実データで事故りやすい内部定義パスやロック中要素を既定で除外
- `判定許容差` を `弱 / 中弱 / 中 / 中強 / 強` の 5 段階で調整
- 更新されたパスを実行後に再選択
- **破損したパスを検出・除外する安全性向上** ✨

## メニュー位置

Inkscape 上では次の位置に出る想定です。

```text
拡張 > エクスポート > 重複ノードを整理
```

## 今回の実装方針

Inkscape の通常拡張は、キャンバス上で次のような対話を直接行うのが苦手です。

- マウスカーソルが触れたパスだけをリアルタイムに水色表示する
- 右クリック時にその場で「適用しますか」と確認する

そのため現実的に運用しやすい形として、拡張を開く前に Inkscape 上で対象パスを選択してから使う方式にしています。

## ファイル構成

- `clean_up_nodes_ink.inx`
- `clean_up_nodes_ink.py`
- `clean_up_nodes_ink_core.py`

## インストール

1. Inkscape の拡張フォルダを開きます。
2. `clean_up_nodes_ink.inx`、`clean_up_nodes_ink.py`、`clean_up_nodes_ink_core.py` をそのフォルダへコピーします。
3. Inkscape を再起動します。

Windows のユーザー拡張フォルダ例:

```text
%APPDATA%\inkscape\extensions
```

## 使い方

1. Inkscape 上で対象のパスを先に選択します。
2. `拡張 > エクスポート > 重複ノードを整理` を開きます。
3. `実行内容` で `整理する` か `チェックのみ` を選びます。
4. 必要に応じて詳細オプションを調整します。
5. 実行します。

`チェックのみ` では path 自体は変更せず、重複候補ペア数、候補ノード数、選択パス内のノード数、ノード種類ごとの数をレポートします。  
`重複候補に赤マーカーを付ける` を有効にすると、候補ノード位置に赤い補助マーカーを作成します。
`整理する` は連続している重複ノードと、閉じたパスのつなぎ目にある重複ノードを対象に統合します。

## 判定の考え方

- `判定許容差` は、見た目の重なりを基準にした 5 段階です。
- 段階は `弱 / 中弱 / 中 / 中強 / 強` です。
- 内部ではそれぞれ `4px / 6px / 8px / 10px / 12px` 相当の半径として扱います。
- 赤マーカーの外側リング半径も、この判定半径と同じです。
- `弱` はかなり近いノードだけを拾い、`強` ほど広めに近接ノードを拾います。

## 既定の安全設定

既定では次の path は除外します。

- `defs`
- `marker`
- `clipPath`
- `mask`
- `pattern`
- `symbol`
- ロックされたレイヤーや要素の中にある path

必要なら拡張ダイアログのチェック項目で対象に含められます。

## 動作仕様

- 連続する 2 つ以上のノードが同じ座標にある場合、それらを 1 つにまとめます。
- 判定は見た目寄りで行い、許容差の半径内にある近接ノードは重複候補としてまとめることがあります。
- まとめたノードはシャープノードになるよう、左右ハンドルをノード位置に引き込みます。
- 対象は SVG の `path` 要素です。
- オプションで、整理後に 1 点だけになったサブパスを削除できます。
- オプションで、更新されたパスを実行後に再選択できます。ノードツールへ切り替えると結果確認がしやすくなります。

## トラブルシューティング

### 「選択中の path が見つかりません」と表示された

- パスを選択してから実行してください
- グループ化されたパスは自動選択されません
- ロック中の要素や内部定義パス（defs など）は既定で除外されます
- 詳細オプションで「ロック中の要素も対象にする」を有効にすれば対象に含められます

### 「破損パス」が除外されたと表示される

- 一部のパスが SVG 形式的に無効な状態です
- コンソールの詳細ログを確認して、どのパス（ID）が問題かを特定できます
- 該当パスを Inkscape で手動確認・修復してください
- または、拡張を再度実行して他のパスだけ処理できます

### 処理後もノードが残っている

- 許容差を高くしてみてください
- 連続していない単なる「近接」ノードは対象外です
- `チェックのみ` で赤マーカーを確認して、対象ノードの実際の距離を確認してください

### 処理中にエラーが出た

- Inkscape のコンソール（Shift+Ctrl+J）でデバッグメッセージを確認してください
- 破損したパスが含まれていないか確認してください
- バックアップを取った上で、もう一度実行してみてください

## ローカル確認

純粋な重複整理ロジックだけは、Inkscape なしでも次のコマンドで確認できます。

```text
python -m unittest test_clean_up_nodes_core.py
```

実行後は、処理したパス数や削除した重複ノード数を日本語メッセージで確認できます。
